# STARCONS Recolor Utility

`recolor.py` is an optional tool for people contributing button artwork to
STARCONS.

It is not required to use STARCONS. Its purpose is to make it easier to create
complete color sets and to add new buttons to existing color sets.

## Master Button Set

The utility treats:

    buttons/Default

as the master button set.

When a new button is added, its Default version should be created first. The
utility can then create colored versions of that button.

The utility works only with PNG files in the selected source directory.

It does not modify the `icons/` or `icons/SVG/` directories.

## Theme Configuration

Configured themes are stored in:

    recolor-themes.json

Themes are grouped into categories such as `manufacturer` and `generic`.

A theme contains:

- `color` - the RGB color used for the theme, written as a six-digit
  hexadecimal color such as `#FF1E00`.
- `partial_tolerance` - how much RGB variation is allowed in partially
  transparent edge pixels when checking existing artwork.

Example:

    "Anvil": {
      "color": "#1FDCB8",
      "partial_tolerance": 13
    }

### Why partial_tolerance exists

Some existing STARCONS manufacturer artwork uses slightly different RGB values
on partially transparent anti-aliased edges.

Those small differences are part of the existing artwork and do not need to be
replaced.

`partial_tolerance` lets the utility recognize that artwork as valid so that it
does not rewrite large numbers of existing files unnecessarily.

A value of `0` means that partially transparent pixels must use the exact
configured color. This is used for the generic color sets generated by this
utility.

The manufacturer tolerance values in the configuration are intended to
preserve the existing artwork. They are not rules for how manufacturer artwork
must be created.

## Interactive Use

Run the utility without arguments:

    python3 recolor.py

The interactive menu can:

1. Generate all configured themes.
2. Generate manufacturer themes.
3. Generate generic color themes.
4. Generate one configured theme.
5. Generate a custom color.
6. Add a new theme to the configuration.
7. Show the configured themes.

## Command-Line Use

Generate all configured themes:

    python3 recolor.py --all

Generate one category:

    python3 recolor.py --category generic

Preview what would change without writing files:

    python3 recolor.py --all --dry-run

Generate a custom color directly:

    python3 recolor.py buttons/Default buttons/MyTheme "#12AB34"

## Dry Run

`--dry-run` performs the checks and reports what would happen without writing
any image files.

This is recommended before making a large change:

    python3 recolor.py --all --dry-run

Review the results before running the same command without `--dry-run`.

## Existing Artwork

During normal configured-theme generation, the utility checks existing images
before replacing them.

The result for each file is reported as:

- `created` - the themed file did not exist and will be created.
- `updated` - the themed file existed but did not match the configured theme.
- `skipped` - the existing themed file is already acceptable and is left alone.
- `error` - the file could not be processed.

For configured themes, an existing image is considered acceptable when:

- its dimensions match the Default master;
- its transparency matches the Default master;
- fully opaque pixels use the configured theme color; and
- partially transparent pixels are within the theme's configured tolerance.

RGB values in completely transparent pixels are ignored because they are not
visible.

This check is especially useful for preserving existing manufacturer artwork
that has anti-aliased edges.

## Force Mode

`--force` deliberately regenerates destination images even when the utility
would normally leave them alone.

For example:

    python3 recolor.py --category generic --force

Use `--force` carefully. It can replace existing artwork.

## Adding a New Theme

A theme can be added through option 6 in the interactive menu.

New themes added this way start with a `partial_tolerance` of `0`.

The configuration file can also be edited by hand if a different tolerance is
needed.

The utility validates theme names, colors, and tolerance values when it loads
the configuration.

## Suggested Contributor Workflow

When adding a new button:

1. Create the new PNG in `buttons/Default`.
2. Run the utility with `--dry-run`.
3. Review which files would be created or updated.
4. Run the utility normally when the results look correct.
5. Review the Git diff before committing.

When creating a completely new color set, add the color to
`recolor-themes.json` or use the interactive menu, then generate the theme from
`buttons/Default`.

The recolor utility is a convenience for contributors. It does not replace the
project owner's normal artwork creation process.
